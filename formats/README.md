# formats/

JSON schemas for every document kind in Spec 1 (library, channels, presets, lists, stacks, outputs, machine settings, the media index), and the `.pro` importer that re-authors a ProPresenter library into Spec 1 documents through the same validator the app uses.

Nothing here yet: the schemas are written alongside the Spec 1 format code, and the importer after it. The fixture library lives in `tests/fixtures/library-v1/` (Spec 1 §10), not here.
